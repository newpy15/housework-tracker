# 배경 사진

스킨별 배경 사진을 이 폴더에 아래 이름으로 넣으면 기본 배경으로 쓰입니다.
파일이 없으면 앱이 직접 그린 일러스트가 대신 나옵니다.

| 파일 | 스킨 |
|---|---|
| `mint.jpg` | 민트 산책 |
| `cream.jpg` | 카페 오후 |
| `night.jpg` | 별밤 |
| `forest.jpg` | 비 오는 숲 |

- 세로(폰 화면)로 쓰기 좋은 사진이 잘 어울립니다. 가로 사진은 가운데를 기준으로 잘려서 보입니다.
- 화질을 위해 세로 1290×2796 이상(요즘 폰 화면 크기)을 권합니다. 이보다 작으면 화면에 맞추려고 늘려 그려서 흐려 보입니다.
- 용량은 장당 1~3MB 정도가 적당합니다. (너무 크면 폰에서 느려집니다)
- 앱의 ⚙️ 설정에서 사진을 고르면 "사진 영역 정하기" 화면에서 쓸 부분을 직접 정할 수 있고, 그 부분이 원본 해상도 그대로 저장됩니다.
- 사용자가 앱의 🎨 꾸미기 창에서 고른 사진이 있으면 이 파일보다 우선합니다.
- 직접 찍었거나 사용 허락을 받은 사진만 넣어 주세요.
